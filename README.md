# Featured Projects

## Embedded Design Capstone Project - Pixel Party
Pixel Party is a table-top game that combines arcade style video games with traditional board game elements, such as dice rolling. Working in a team of four, we designed and built PCB featuring a STM32 microcontroller. We programmed the microcontroller to interface with numerous physical inputs while also simultaneously interfacing with a Raspberry Pi single board computer over UART. The single board computer computed game play logic and a graphical user interface.

### Skills and Technologies:
* Custom PCB and soldering
* Embedded C and STM32 microcontroller programming
* UART protocol
* Hardware-software integration
* Hardware testing
* Godot

## Pipelined Dual-core RISC-V Processor
As part of my Computer Design and Prototyping course at Purdue, I designed, implemented, and tested a dual-core RISC-V processor in SystemVerilog. Each core featured a five-stage pipeline designed with hazard detection, handling, and forwarding. The processor also incorporates private L1 instruction and data caches for each core.

### Skills and Technologies:
* SystemVerilog and RTL Design
* Processor pipelining and hazard handling
* Caches architecture
* Simulation and verification through QuestaSim
* FPGA synthesis and timing Analysis

The source repository for this project is not publicly available.

For my Microprocessor Systems and Interfacing course, I worked in a team of four to develop a game inspired by Piano Tiles, controlled using a thumb joystick.
